Working Process

A simple internal system for handling office, people, and admin work.

This is a process page I built from the team’s actual daily work at Ather Labs. It groups recurring tasks into clear workstreams so people know what to do, who to contact, and what to track.

Short version: request comes in, classify it, check info, contact the right person, complete the task, update tracking, and follow through until done.

Control Points

Important notes inside the file

A few parts are especially important because they affect money, approvals, tracking, and asset handover.

C1
Payment request timing
The file notes when admin payment requests should be submitted and how long accounting may take to process them.
This helps set expectation early.
C2
Approval and document check
The file shows when approval is needed first and reminds the team to attach the right supporting documents.
Especially important for equipment purchases.
C3
Tracking is mandatory
Tasks are not really done until records are saved and the tracking file is updated.
That keeps the work visible for the team later.
E
New joiner readiness
Onboarding is broken into practical needs like seat, machine, monitor, software, accessories, and access cards.
F
Exit closure logic
Offboarding has a defined flow so asset return and admin closure are easier to manage.
I
Cross-office asset visibility
Separate asset tracking for HCMC and Da Nang helps the team monitor where items are and who holds them.

# Duong Tran Portfolio

Personal work portfolio for Duong Tran, written for recruiters.

The site presents work across HR, Operations, PR and Events.

## What is on the site

- `index.html` - portfolio home
- `work/index.html` - Selected Work across HR, Operations, PR and Events
- `work/recruitment-dashboard.html` - recruitment dashboard using sample data
- `work/ai-case-payment.html` - AI case study on a payment workflow
- `assets/docs/duong-tran-cv.pdf` - CV download
- `assets/docs/duong-tran-cv.html` - CV page
- `assets/images/profile.png` - profile image

The recruitment dashboard on this public site uses sample data, not live hiring numbers.

## Local preview

Open `index.html` in a browser.

## Publish with GitHub Pages

This repository is configured to publish from the `main` branch root.

After pushing updates:
1. Go to GitHub repository settings
2. Open **Pages**
3. Confirm source is **Deploy from branch**
4. Select `main` and `/ (root)`

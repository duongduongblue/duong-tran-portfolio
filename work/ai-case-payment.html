Case study · Operations

Recurring payments, on autopilot.

How I used AI agents to turn a manual monthly payment routine into a tracked, self-reminding system.

The problem

Recurring vendor payments across three offices (Da Nang, HCM and Hanoi) were tracked by memory and scattered files.

  • Missed or late payment requests were only noticed when a vendor chased.
  • Contract expiry dates were hidden inside signed documents.
  • Each request took several manual steps across forms, folders and chat threads.

What I built

Four pieces, each designed by me and executed with an AI agent.

Master tracking sheet

  • Built from real past payments, not a blank template.
  • Formulas flag unpaid months and expiring contracts.
  • Colour-coded warnings at a glance.

Weekly expiry alert

  • Runs every Monday morning.
  • Lists contracts nearing expiry and missing requests.

Monthly review

  • Runs on the 25th each month.
  • Summarises paid vs. pending vendors in one easy page.

Standard request flow

  • Same steps every time: prepare, merge, file, log, notify.
  • Messages are drafted for my review, never sent automatically.

How I worked with AI

I set the rules; the agent did the repetitive work.

My role

  • Defined the process, formats and checkpoints.
  • Approved every outgoing message.
  • Corrected the system when real cases broke it.

The agent's role

  • Read invoices and fill request forms.
  • Organise files and update the tracker.
  • Run scheduled checks and report back.

Result

A routine I can run from the tracker, not from memory.

  • Every recurring vendor is visible in one place.
  • Expiring contracts surface weeks ahead, not after the fact.
  • The steps and tracker are written down, so the routine does not depend on memory.
